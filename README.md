# ✍️ Essay Similarity Checker (PHP Web App)

✌ Hello! This project is a **web-based application** developed in **PHP** that detects **similarities between two essays** by comparing them **sentence by sentence** and calculating the **percentage of common words**.

## ✨ Overview

Cheating and plagiarism in essays are common issues. This tool helps to detect potential copy-paste behavior by analyzing:

- Sentence-level similarity
- Word overlap ratio
- Final similarity percentage

## 🛠️ Requirements

To run this project locally, you need:

- ✅ [XAMPP](https://www.apachefriends.org/) installed (includes Apache + PHP)
- ✅ A modern web browser
